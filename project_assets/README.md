# أصول مشروع مواكبة للموارد البشرية
## Muwakaba HR Platform - Project Assets

### هيكل المجلدات / Folder Structure

```
project_assets/
├── images/          → صور الخلفية والشعارات والصور المرفوعة
├── icons/           → أيقونات الخدمات (مولّدة بالذكاء الاصطناعي)
├── documents/
│   ├── pdf/         → ملفات PDF (نظام العمل، التأمينات، الموارد البشرية)
│   ├── word/        → نماذج Word (عقود، طلبات، إجراءات)
│   ├── excel/       → نماذج Excel (متابعة الإجازات، القوى العاملة)
│   └── other/       → ملفات أخرى
├── uploads/         → الملفات المرفوعة من المستخدم
└── fonts/           → الخطوط (Cairo + Noto Naskh Arabic من Google Fonts)
```

### الخطوط المستخدمة / Fonts Used
- Cairo (Google Fonts)
- Noto Naskh Arabic (Google Fonts)
- Scheherazade New (Google Fonts)

### الأيقونات المولّدة / AI-Generated Icons
- org_chart_icon.png → أيقونة الهيكل التنظيمي
- workforce_planning_icon.webp → أيقونة تخطيط القوى العاملة
- muwakaba_logo.webp → شعار مواكبة
